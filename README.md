## What I Work On

### Document AI & OCR

面向复杂文档的版面分析、文字检测识别、表格解析与内容提取，关注印章干扰、长标题及多模型结果融合等实际问题。

### Efficient Inference

围绕 `PyTorch → ONNX → TensorRT / OM / RKNN` 构建部署链路，结合 NVIDIA DALI 与 Triton Ensemble / BLS 优化预处理和多模型推理流程。

### Visual Search & Retail Intelligence

结合目标检测、实例分割、细粒度识别与 FAISS 向量检索，实现商品识别、相似图像检索及价签与商品关联。

### Edge AI & Interaction

关注端侧算子适配、混合精度量化、检测模型后处理，以及基于手部关键点的实时手势交互。

## Public Project
